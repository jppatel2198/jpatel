Financial Decision Analysis

Cash Is King | Northeastern University

An analysis of financial decision scenarios using spreadsheet models to evaluate business performance and compare alternative management decisions.

  • Built spreadsheet models to evaluate financial decision scenarios
  • Ran sensitivity analysis to test how changes in key assumptions affect outcomes
  • Assessed the financial implications of alternative management decisions
  • Translated the analysis into recommendations on business performance
Read the case study
The challenge

Management faced several possible decisions, each with different financial consequences. The task was to work out which path would best support business performance, knowing that real-world assumptions rarely hold steady.

My approach

I built spreadsheet models of each decision scenario, then ran sensitivity analysis to see how the results changed as key assumptions moved.

  1. ModelBuild the scenarios in a spreadsheet
  2. Stress-testShift key assumptions one at a time
  3. CompareWeigh each decision's financial impact
  4. RecommendTurn the numbers into a decision
The outcome

A recommendation backed by modeled financial implications, with a clear view of which assumptions mattered most and how robust each option was.
